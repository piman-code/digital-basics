  3. 한 단계를 끝내면 큰 「✔ 했어요」 버튼을 눌러요. 위쪽 초록 막대가 차올라요.

🧰 자주 막히는 5가지

📩 1. 인증번호(코드)가 안 와요

  • 입력한 내 폰 번호가 맞는지 한 자리씩 다시 봐요.
  • 국가를 고르는 칸이 있으면 대한민국인지 확인해요.
  • 조금 기다린 다음 「다시 보내기」나 「재전송」을 눌러요. [화면이 다를 수 있어요]
  • 폰의 문자 앱을 열어 봐요. 스팸 문자함이나 차단 문자함도 봐요.
  • 번호를 여러 번 받았다면 가장 마지막에 온 번호를 넣어요.
  • 인증번호는 시간 제한이 있어요. 시간이 지나면 새로 받아요.
  • 여러 번 해도 안 오면 계속 누르지 말고 손을 들어요.

🆔 2. "이미 사용 중인 아이디"라고 나와요

  • 누군가 벌써 쓰고 있다는 뜻이에요. 내 잘못이 아니에요 🙂
  • 뒤에 숫자나 단어를 붙여 봐요. 예) ○○○ → ○○○1023, ○○○_study
  • 화면에 나오는 추천 아이디를 눌러서 골라도 돼요.
  • 정한 아이디는 📝 메모장에 꼭 적어요.

🔑 3. 비밀번호가 안 된대요

  • 칸 아래 빨간 안내 문구를 읽고 그대로 고쳐요. 사이트마다 규칙이 달라요.
  • 더 길게 만들고, 영어 + 숫자 + 기호를 섞어 봐요.
  • "일치하지 않음"이 나오면 두 칸을 다 지우고 천천히 다시 써요.
  • 키보드가 대문자로 고정됐는지 봐요. (위쪽 화살표 ⇧ 키)
  • 👁️ 눈 모양을 누르면 쓴 글자가 보여요. 확인한 뒤 다시 눌러서 가려요. 옆 사람이 못 보게!
  • 아래 ⭐ 안전한 비밀번호 게임에서 만드는 법을 연습할 수 있어요.

🙋 4. 이미 계정이 있대요 / 원래 있었어요

  • 새로 만들지 않아도 돼요! 원래 있던 계정으로 로그인만 해요.
  • 아이디가 생각나지 않으면 로그인 화면의 「아이디 찾기」(네이버)나 「이메일을 잊으셨나요?」(구글)를 눌러요. [화면이 다를 수 있어요]
  • 로그인이 되면 그 파트 단계들은 「✔ 했어요」로 체크해도 괜찮아요.

🤯 5. 비밀번호를 잊어버렸어요

  • 여러 번 마구 넣어 보지 않아요. 계정이 잠시 막힐 수 있어요.
  • 로그인 화면의 「비밀번호 찾기」(네이버)나 「비밀번호를 잊으셨나요?」(구글)를 눌러요. [화면이 다를 수 있어요]
  • 화면 안내대로 내 폰으로 인증하고, 새 비밀번호를 만들어요.
  • 리로스쿨 비밀번호는 학교 안내를 따르고, 모르겠으면 손을 들어요.
