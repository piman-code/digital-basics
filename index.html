1구글 계정 만들기

구글 계정이 있으면 Gmail, 유튜브, 구글 드라이브를 쓸 수 있어요.

🎯 목표: 내 Gmail 주소(○○○@gmail.com)를 하나 만들어요.
🧰 준비물: 내 휴대폰 (인증 문자를 받을 수도 있어요)

  1. 인터넷 창(크롬 등)을 열고, 주소창에 accounts.google.com을 입력해요.

    맨 위의 긴 입력칸이 주소창이에요. 입력하고 Enter를 눌러요.

    스크린샷 자리
    브라우저 주소창에 주소 입력하는 모습
    막히면 이렇게
    • 주소를 한 글자씩 다시 확인해요. (점 . 위치!)
    • 검색창에 입력해도 괜찮아요. 결과에서 google.com으로 끝나는 주소를 눌러요.

  2. 계정 만들기 버튼을 누르고, 개인용을 골라요. [화면이 다를 수 있어요]

    스크린샷 자리
    로그인 화면 아래쪽 '계정 만들기' 버튼
    막히면 이렇게
    • 버튼은 보통 로그인 화면의 아래쪽에 있어요.
    • 이미 다른 계정으로 로그인되어 있으면, 오른쪽 위 동그란 프로필 → 다른 계정 추가를 찾아봐요.

  3. 성과 이름을 입력하고 다음을 눌러요.

    스크린샷 자리
    성 · 이름 입력 칸
    막히면 이렇게
    • 한글로 써도 괜찮아요.
    • 다음 버튼이 안 보이면 화면을 아래로 내려 봐요.

  4. 생년월일과 성별을 입력해요.

    스크린샷 자리
    생년월일 · 성별 선택 칸
    막히면 이렇게
    • 진짜 생일을 정확히 넣어요. 나이가 틀리면 나중에 일부 기능이 제한될 수 있어요.
    • '월'은 눌러서 목록에서 골라요.

  5. Gmail 주소를 정해요. 추천 주소를 고르거나 직접 만들어요.

    이게 앞으로 내 아이디예요. 정했으면 위 📝 메모장에 적어요.

    스크린샷 자리
    Gmail 주소 고르기 / 직접 만들기
    막히면 이렇게
    • "이미 사용 중"이라고 나오면 뒤에 숫자를 붙여 봐요. (예: ○○○1023)
    • 영어 소문자, 숫자, 마침표(.)를 써요. 한글은 안 돼요.
    • 나중에 선생님·학교에 보여줄 수 있는 단정한 주소로 해요.

  6. 비밀번호를 만들고, 한 번 더 똑같이 입력해요.

    스크린샷 자리
    비밀번호 · 확인 입력 칸
    막히면 이렇게
    • 화면에 나오는 규칙대로 문자 + 숫자 + 기호를 섞어서 길게 만들어요.
    • "일치하지 않음"이 나오면 두 칸을 다 지우고 천천히 다시 입력해요.
    • 눈 모양(또는 '비밀번호 표시')을 누르면 입력한 글자가 보여요. 옆 사람이 보지 않게 조심!
    • ⚠️ 생일, 전화번호, 1234 같은 비밀번호는 쓰지 않아요.

  7. 전화번호 확인이 나오면, 내 번호를 넣고 문자로 온 인증코드를 입력해요. [화면이 다를 수 있어요]

    이 단계는 나올 때도 있고, 안 나올 때도 있어요.

    스크린샷 자리
    전화번호 입력 · 인증코드 입력 칸
    막히면 이렇게
    • 문자가 안 오면 1~2분 기다린 뒤 다시 보내기를 눌러요.
    • 국가가 대한민국으로 되어 있는지 확인해요.
    • 🔐 인증코드는 나만 봐요. 친구에게도 불러 주지 않아요.

  8. 복구 이메일 화면이 나오면, 있으면 입력하고 없으면 건너뛰기를 눌러요. [화면이 다를 수 있어요]

    스크린샷 자리
    복구 이메일 입력 / 건너뛰기
    막히면 이렇게
    • 복구 이메일·복구 전화번호는 비밀번호를 잊었을 때 도움이 돼요. 나중에 추가해도 돼요.

  9. 개인정보 보호 및 약관을 읽고 동의를 눌러요.

    스크린샷 자리
    약관 화면 맨 아래 '동의' 버튼
    막히면 이렇게
    • 버튼이 안 보이면 화면을 끝까지 아래로 내려요.
    • 무슨 내용인지 궁금하면 선생님께 물어봐도 좋아요.

  10. 오른쪽 위에 동그란 프로필이 보이면 성공! 🎉

    스크린샷 자리
    로그인된 화면 오른쪽 위 프로필 아이콘
    막히면 이렇게
    • 프로필을 눌러서 내 Gmail 주소가 맞는지 확인해요.
    • 메모장에 주소를 적었는지 다시 확인해요. (비밀번호는 ❌)

2네이버 계정 만들기

네이버 계정으로 메일, 카페, 블로그 등을 쓸 수 있어요.

🎯 목표: 내 네이버 아이디를 하나 만들어요.
🧰 준비물: 내 휴대폰 (휴대전화 본인인증을 해요)

  1. 주소창에 naver.com을 입력하고, 로그인을 눌러요.

    스크린샷 자리
    네이버 첫 화면의 로그인 버튼
    막히면 이렇게
    • 폰에서는 화면 위쪽의 사람 모양이나 메뉴(☰)에 로그인이 있을 수 있어요. [화면이 다를 수 있어요]

  2. 로그인 화면 아래쪽 회원가입을 눌러요. [화면이 다를 수 있어요]

    스크린샷 자리
    로그인 화면 아래 '회원가입' 글자
    막히면 이렇게
    • 작은 글씨로 되어 있을 수 있어요. 화면 아래쪽을 잘 살펴봐요.

  3. 약관 동의에서 필수 항목에 체크하고 다음으로 가요.

    스크린샷 자리
    약관 동의 체크 화면
    막히면 이렇게
    • [필수] 표시된 칸에 모두 체크해야 다음으로 넘어가요.
    • [선택] 항목은 안 해도 가입할 수 있어요.

  4. 아이디를 입력해요.

    스크린샷 자리
    아이디 입력 칸과 안내 문구
    막히면 이렇게
    • 칸 아래에 빨간 글씨가 나오면 그 안내대로 고쳐요. (예: 이미 사용 중, 쓸 수 없는 글자)
    • 영어 소문자와 숫자 위주로 만들면 쉬워요.
    • 정했으면 📝 메모장에 적어요.

  5. 비밀번호를 입력해요. 구글과 다른 비밀번호로 만들어요.

    스크린샷 자리
    비밀번호 입력 칸
    막히면 이렇게
    • 칸 아래 안내 문구를 읽고 규칙에 맞게 바꿔요.
    • 사이트마다 비밀번호를 다르게 하면, 하나가 털려도 나머지는 안전해요.

  6. 이름, 생년월일, 성별 등 화면에 나오는 정보를 입력해요. [화면이 다를 수 있어요]

    스크린샷 자리
    이름 · 생년월일 · 성별 입력 칸
    막히면 이렇게
    • 이름은 휴대폰 명의자 이름과 똑같이 써야 본인인증이 돼요.
    • 이메일 칸이 [선택]이면 비워 둬도 돼요.

  7. 통신사를 고르고 휴대전화번호를 넣은 뒤, 인증요청을 눌러요. [화면이 다를 수 있어요]

    스크린샷 자리
    통신사 선택 · 전화번호 · 인증요청 버튼
    막히면 이렇게
    • 내 통신사를 모르면 폰 설정이나 요금 문자에서 확인할 수 있어요.
    • 알뜰폰이면 '알뜰폰' 항목을 찾아 골라요.
    • 폰이 부모님 명의면 인증이 안 될 수 있어요. 손을 들어 선생님께 알려요.

  8. 문자로 온 인증번호를 입력하고, 가입하기를 눌러요.

    스크린샷 자리
    인증번호 입력 칸 · 가입하기 버튼
    막히면 이렇게
    • 인증번호는 시간 제한이 있어요. 시간이 지나면 재전송을 눌러요.
    • 문자가 스팸함에 들어갔는지도 확인해요.
    • 🔐 인증번호는 절대 다른 사람에게 알려 주지 않아요.

  9. 가입 완료! 만든 아이디로 로그인이 되는지 확인해요. 🎉

    스크린샷 자리
    로그인된 네이버 화면
    막히면 이렇게
    • 로그인할 때 '로그인 상태 유지'는 공용 컴퓨터라면 체크하지 않아요.
    • 비밀번호가 틀리면 Caps Lock(대문자 고정)이 켜져 있는지 확인해요.

3리로스쿨 접속하기

리로스쿨은 학교 공지, 과제 등을 확인하는 우리 학교 사이트예요.

🎯 목표: 우리 학교 리로스쿨에 들어가서 로그인하고, 즐겨찾기까지 해요.
📍 우리 학교 주소: OO고 리로스쿨 주소 (선생님이 칠판이나 공지로 알려 줘요)

  1. 주소창에 OO고 리로스쿨 주소를 입력해요.

    스크린샷 자리
    주소창에 학교 리로스쿨 주소 입력
    막히면 이렇게
    • 검색창이 아니라 주소창에 입력해요.
    • 학교마다 주소가 달라요. 꼭 선생님이 알려 준 주소를 써요.
    • "페이지를 찾을 수 없음"이 뜨면 글자를 하나씩 다시 비교해요.

  2. 첫 화면에서 로그인(처음이면 회원가입) 버튼을 찾아요. [화면이 다를 수 있어요]

    스크린샷 자리
    리로스쿨 첫 화면의 로그인 / 회원가입
    막히면 이렇게
    • 버튼 위치는 학교 화면마다 다를 수 있어요. 화면 위쪽이나 가운데를 살펴봐요.

  3. 학교에서 안내한 방법대로 가입하거나 로그인해요.

    어떤 정보를 넣어야 하는지는 학교마다 달라요. 선생님 안내를 따라요.

    스크린샷 자리
    리로스쿨 로그인 / 가입 입력 화면
    막히면 이렇게
    • 가입 후 승인 대기처럼 보이면, 학교에서 승인해 줘야 쓸 수 있는 경우일 수 있어요. 선생님께 알려요.
    • 이미 가입했는데 비밀번호를 모르겠으면, 혼자 여러 번 시도하지 말고 선생님께 물어봐요.
    • 아이디는 📝 메모장에 적어요.

  4. 다음에 바로 들어올 수 있게 즐겨찾기(북마크)에 추가해요.

    💻 컴퓨터: Ctrl + D (맥은 ⌘ + D) 또는 주소창 오른쪽 ☆ 별 누르기
    📱 폰: 브라우저 메뉴(⋮ 또는 공유 버튼)에서 북마크 / 홈 화면에 추가 찾기 [화면이 다를 수 있어요]

    스크린샷 자리
    주소창 오른쪽 별(☆) 아이콘
    막히면 이렇게
    • 공용 컴퓨터에서는 즐겨찾기 대신 내 폰에 추가해 두면 좋아요.

  5. 다 봤으면 로그아웃을 눌러요.

    스크린샷 자리
    로그아웃 버튼 위치
    막히면 이렇게
    • 로그아웃 버튼은 내 이름 근처나 메뉴 안에 있을 수 있어요. [화면이 다를 수 있어요]
    • 찾기 어려우면 브라우저 창을 완전히 닫고, 선생님께 확인해요.

계정을 만들었으면, 이제 지키는 법을 알아야 해요.

🔑

1. 비밀번호 지키기

  • 길게, 문자·숫자·기호를 섞어요.
  • 생일, 전화번호, 이름, 1234는 ❌
  • 사이트마다 다르게 만들어요.
  • 친구에게도, 단톡방에도 절대 알려 주지 않아요.
  • 가능하면 2단계 인증을 켜 두면 더 안전해요.
🎣

2. 피싱 · 수상한 링크 조심

피싱은 가짜 문자나 사이트로 내 정보를 훔치는 사기예요. 이런 신호가 보이면 링크를 누르지 않아요.

  • "지금 바로!", "계정 정지 예정" 처럼 급하게 재촉해요.
  • 모르는 번호에서 온 링크가 있어요.
  • 주소 글자가 진짜와 살짝 달라요. (예: 글자 하나 바뀜)
  • 상품권, 당첨, 택배 확인 등으로 클릭을 유도해요.
🔐

3. 인증번호는 나만 봐요

문자로 온 인증번호·인증코드를 달라고 하면, 친구든 회사 직원이라고 하든 주지 않아요. 인증번호를 넘기면 다른 사람이 내 계정에 들어올 수 있어요.

🖥️

4. 공용 컴퓨터에서는 꼭 로그아웃

  • 다 쓰면 로그아웃 → 브라우저 창 닫기.
  • '로그인 상태 유지' 체크 ❌
  • "비밀번호를 저장할까요?" → '안 함' 또는 '저장 안 함'
  • 시크릿 창(크롬: Ctrl+Shift+N)을 쓰면 창을 닫을 때 방문 기록이 남지 않아요. 그래도 로그아웃은 꼭 해요.
🪪

5. 개인정보 아끼기

  • 주민등록번호, 집 주소, 전화번호는 꼭 필요한 곳에만 입력해요.
  • SNS에 학교·반·집 위치가 드러나는 사진은 조심해요.
  • 신분증, 인증 화면 캡처는 함부로 보내지 않아요.

✅ 이렇게 해요

  • 이상하면 일단 멈추기
  • 공식 앱·주소로 직접 들어가서 확인
  • 보호자·선생님께 먼저 물어보기
  • 쓰고 나면 로그아웃

⛔ 이건 안 돼요

  • 모르는 문자 속 링크 누르기
  • 인증번호 알려 주기
  • 친구와 비밀번호 공유
  • 공용 PC에 비밀번호 저장

🧩 깜짝 퀴즈 (눌러서 정답 보기)

이런 문자가 왔어요. 링크를 눌러도 될까요?
[알림] 고객님 택배가 주소 불일치로 보관 중입니다. 확인: http://○○○.○○/abc
❌ 누르지 않아요. 모르는 번호 + 링크 + 확인 재촉은 피싱의 대표적인 신호예요. 택배가 걱정되면 내가 쓰던 공식 앱이나 사이트에 직접 들어가서 확인해요.
친구가 "내 폰 고장 났어, 너한테 간 인증번호 좀 불러줘"라고 해요.
❌ 알려 주지 않아요. 인증번호는 나만 써야 해요. 친구 계정이 해킹당해서 다른 사람이 보낸 메시지일 수도 있어요. 전화로 직접 확인해 봐요.
학교 컴퓨터에서 리로스쿨을 다 썼어요. 그냥 창만 닫아도 될까요?
❌ 로그아웃 먼저! 로그아웃 → 창 닫기 순서로 해요. '로그인 상태 유지'가 켜져 있으면 다음 사람이 내 계정을 볼 수 있어요.

  1. 안전 수칙 5가지를 읽고, 퀴즈 3개를 풀어 봤어요.

    막히면 이렇게
    • 퀴즈는 질문을 누르면 정답이 펼쳐져요.
    • 헷갈리는 수칙은 옆 친구와 이야기해 보거나 선생님께 물어봐요.

5원서접수 기초

대학·자격증·대회 등 온라인 접수는 대부분 비슷한 순서로 진행돼요. 오늘은 연습용 예시로 흐름만 익혀요.

🎯 목표: 접수 순서를 알고, 마감일과 접수번호를 챙기는 습관을 들여요.
📍 예시 사이트: OO 원서접수 사이트 (예시)
※ 실제 사이트마다 순서·화면·필요 서류가 달라요. 반드시 그 사이트의 모집요강·공지를 따라요.
① 공지 확인→② 로그인→③ 정보 입력→④ 서류 올리기→⑤ 최종 확인→⑥ 결제(있으면)→⑦ 접수번호 저장

  1. 모집요강·공지에서 마감 날짜와 시각을 먼저 확인해요.

    📅 날짜뿐 아니라 몇 시까지인지도 봐요. 달력이나 폰 알람에 적어 둬요.

    스크린샷 자리
    공지사항의 접수 기간 · 마감 시각 부분
    막히면 이렇게
    • 마감 직전에는 사람이 몰려서 느려질 수 있어요. 여유 있게 미리 접수해요.
    • "접수 기간", "마감", "일정" 같은 단어를 찾아봐요.

  2. 필요한 서류 목록을 확인하고, 파일을 미리 준비해요.

    예) 증명사진, 자기소개서, 증빙 서류 등 — 사이트마다 달라요.

    스크린샷 자리
    제출 서류 · 파일 형식 · 용량 안내
    막히면 이렇게
    • 파일 형식(예: PDF, JPG)과 용량 제한이 적혀 있는지 봐요.
    • 한글 문서를 PDF로 바꾸는 방법은 ⑥ 한글에서 배워요.

  3. 사이트에 로그인하고 원서 작성(또는 접수하기)을 눌러요. [화면이 다를 수 있어요]

    스크린샷 자리
    '원서 작성' / '접수하기' 버튼
    막히면 이렇게
    • 처음이면 회원가입이 먼저 필요할 수 있어요.
    • 사이트가 안전한지 걱정되면 학교 공지에 나온 주소로 들어가요.

  4. 정보를 입력하고 서류를 올린 뒤, 최종 확인 화면을 꼼꼼히 봐요.

    스크린샷 자리
    입력 내용 최종 확인 화면
    막히면 이렇게
    • 제출하면 고칠 수 없는 경우가 많아요. 이름, 생년월일, 연락처, 지원 항목을 한 번 더 봐요.
    • 파일이 안 올라가면 형식과 용량을 다시 확인해요.

  5. 접수가 끝나면 접수번호(수험번호)를 꼭 저장해요.

    📸 화면 캡처 + 📝 메모 + 🖨️ 접수증 PDF 저장/출력 — 두 가지 이상으로 남겨 두면 안심이에요.

    스크린샷 자리
    접수 완료 화면의 접수번호
    막히면 이렇게
    • 캡처: 💻 윈도우 Win+Shift+S / 📱 폰은 기종마다 달라요. [화면이 다를 수 있어요]
    • 나중에 마이페이지·접수 확인 메뉴에서 접수가 잘 됐는지 다시 확인해요.

6한글(HWP) 문서 기초

학교 서류는 한글 파일(.hwp)이 많아요. 열고, 쓰고, 저장하고, PDF로 바꾸는 것까지 해 봐요.

🎯 목표: 「내 소개」 문서를 만들어 규칙에 맞는 이름으로 저장하고, PDF로도 저장해요.
🧰 준비물: 한컴오피스 한글이 설치된 컴퓨터 (이 실습은 컴퓨터로 해요)
※ 한글 버전에 따라 메뉴 이름·위치가 다를 수 있어요.

  1. 한글 프로그램을 열어요.

    윈도우 시작(⊞)을 누르고 "한글"이라고 검색해요.

    스크린샷 자리
    시작 메뉴에서 '한글' 검색
    막히면 이렇게
    • 바탕화면에 파란 '한' 모양 아이콘이 있는지도 찾아봐요. [화면이 다를 수 있어요]
    • 설치가 안 되어 있으면 손을 들어요.

  2. 새 문서를 열어요. (이미 있는 파일은 파일 → 불러오기)

    스크린샷 자리
    한글 시작 화면 · 새 문서
    막히면 이렇게
    • 받은 .hwp 파일은 더블클릭해도 열려요.
    • 시작 화면이 나오면 '새 문서' 또는 빈 문서를 골라요. [화면이 다를 수 있어요]

  3. 흰 종이를 한 번 클릭하고, 내 소개를 세 줄 써요.

    예) ① 좋아하는 것 ② 요즘 관심 있는 것 ③ 오늘 배운 것 하나 (실제 주소·전화번호는 쓰지 않아요!)

    스크린샷 자리
    한글 문서에 글을 입력한 모습
    막히면 이렇게
    • 영어만 나오면 한/영 키를 눌러요.
    • 줄 바꾸기는 Enter, 지우기는 Backspace.
    • 실수하면 Ctrl+Z로 되돌려요.
    • 글자 크기는 글자를 드래그해서 고른 뒤, 위쪽 숫자(글자 크기) 칸에서 바꿔요.

  4. 파일 → 다른 이름으로 저장하기를 눌러요. (단축키 Alt+V)

    ① 저장 위치(예: 바탕화면, 문서)를 고르고 ② 파일 이름을 쓰고 ③ 저장을 눌러요.

    스크린샷 자리
    다른 이름으로 저장하기 창 (위치 · 파일 이름 · 저장)
    막히면 이렇게
    • 저장한 뒤 고친 내용은 저장하기(Alt+S)로 덮어써요.
    • 어디에 저장했는지 모르겠으면 저장 창 위쪽의 위치를 다시 봐요.
    • 학교 컴퓨터는 껐다 켜면 파일이 지워질 수 있어요. USB나 구글 드라이브에도 올려 두면 안전해요.

  5. PDF로 저장해요. 파일 메뉴에서 PDF로 저장하기를 찾아요. [화면이 다를 수 있어요]

    PDF는 어느 기기에서 열어도 모양이 똑같아서, 제출용으로 많이 써요.

    스크린샷 자리
    파일 메뉴의 'PDF로 저장하기'
    막히면 이렇게
    • 메뉴가 안 보이면 인쇄 창에서 프린터를 PDF 항목으로 바꿔서 저장하는 방법도 있어요. 버전에 따라 달라서, 손을 들어 함께 찾아봐요.
    • 저장 후 PDF 파일을 열어서 내용이 잘 들어갔는지 확인해요.

  6. 파일 이름을 규칙에 맞게 지어요.

    추천 규칙: 날짜_학번_이름_내용 (학교·선생님이 정한 규칙이 있으면 그걸 따라요)

    파일 이름어때요?
    20261023_20000_OOO_내소개.hwp👍 좋아요
    20261023_20000_OOO_내소개.pdf👍 PDF도 같은 이름
    새 문서1.hwp👎 무슨 파일인지 몰라요
    최종_진짜최종_ㄹㅇ최종.hwp👎 헷갈려요
    막히면 이렇게
    • 띄어쓰기 대신 밑줄( _ )을 쓰면 깔끔해요.
    • \ / : * ? " < > | 같은 기호는 파일 이름에 쓸 수 없어요.
    • 이미 저장한 파일 이름은 파일 탐색기에서 파일을 클릭하고 F2를 눌러 바꿀 수 있어요.
